# 作品資料 (ネタバレあり)

原作はウズで配信中の 3 人用マダミス (作：アラン校長)。台本・手帳・共通情報・分岐・得点は原作どおりで、scenario.json に起こしてある。原作の仕様書は [original/](../original/README.md)。

## 体験させたいこと

- 最小構成のマダミスを、初めての人でも迷わず最後まで遊べること
- 推理の核は「時間割の整理」と「被害者は本物の斜六か」の 2 つ。原作どおり口頭で整理させる
- タイトルの意味 (「“伝説の探偵”殺人事件を見事解決」) が紙面で回収される瞬間

## 原作から足したもの (Code Modeプレイアビリティのため)

| 足したもの | 理由 |
|---|---|
| 議論中の出来事 (共通情報を議論の途中で少しずつ出す。手荷物検査は各自がカバンを開け、スタッフには質問を選んで聞く) | 原作は議論の開始時に全部を公開する。3 人だと情報を一度に読み切れず議論が散りやすいので、話題が 1 つずつ卓に落ちるようにする。出来事はカットインとダイアログで全員に同時に見せる。操作しなくても 45 秒でスタッフが済ませ、情報は必ず全部出る。議論は時間いっぱい続け、プレイヤーからは切り上げない |
| 見取り図 (場所を押すと関わる共通情報が出る) | 原作の間取り図をそのまま読める形にし、場所と証言を結び付けやすくする |
| 遊び方を語りの声で流す (誰でもない語り部が 1 行ずつ読み、声の長さで自動で進む) | 原作は遊び方も読み合わせで、初対面の 3 人が最初にルール説明を読み上げることになる。聞くだけにして、最初の読み合わせは事件の場面からにする。語りの台本は原作の遊び方を縮めて書き直した文 |
| 投票の間はマイクを切る (場面の間は本人も戻せない) | 原作の「投票は相談不可」を仕組みで守る。切れたマイクは自動では戻らないので、戻すまで上の帯に知らせを出す |
| スタッフ 3 人に別々の立ち絵 (掃除・点検・案内) | 原作は名前の無いスタッフで、同じ顔だと証言の札で誰の話か見分けにくい |
| 遊び方を全員の同意で飛ばせる | 原作でも経験者だけなら省略可。1 人でも初心者がいれば聞く |
| 投票と自己申告を 1 画面にまとめる | 春見の待ち時間を減らす。申告は夏野・秋永だけに出る |
| 開票の画面 | 誰が誰に入れたかを止めて見せてから結末へ進む (自己申告は結末と感想戦で分かるので伏せる) |
| 感想戦の得点表 | 原作の得点表どおりに目標ごとの達成を出す |
| 読み合わせの「代わりに送る」 | 担当が離席して同じ行で 30 秒止まったら、ほかの人が送れる。進行管理席の居ない卓でも止まらない |

## 情報の公開タイミング (原作どおり)

あらすじ・登場人物はロビーから、手帳は読み込みの時間から本人だけ、共通情報と見取り図は議論から（共通情報は議論の途中の出来事で少しずつ）、真相・全員の手帳・全結末は感想戦で。スタッフの台詞（出来事の声かけ）はこの版で書き足した文。
