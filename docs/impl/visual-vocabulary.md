# 視覚語彙

## 意匠の意図

一冊の探偵小説を 3 人でめくる。カバー絵の紺布と額縁を地に、読む面は本文紙、場面が変わると章扉が立つ。タイトル回収 (エンディング 1・2) は「翌日の朝刊」の紙面で見せる。35 分の軽い作品なので、装飾は罫と紙の重なりまでに留める。

## 軸とチャンネル

同じチャンネルを 2 つの軸に使わない。

| 軸 | 値 | チャンネル | トークン |
|---|---|---|---|
| 帰属 | 自分 / それ以外 | 色相 (箔の金)。自分の顔の輪・自分の行・自分の番の台詞札・「あなた」 | `--self*` |
| 押せる | 押せる / 読むだけ | ☞ (活版の指差し) が付く | `Button` の `mark` |
| 状態 | 未 / 済 / 選択 / 無効 | 明度。選択は紙色で立てる、無効は色を落とす (透かさない)、表明中 (読み終えた等) は箔の縁 | `--surface-paper*` / `--text-on-cloth-faint` |
| 熱 | 残りわずか / 犯人の自覚 | 朱。終盤のタイマーと、犯人の手帳の見出し罫だけ | `--heat*` |
| 目立ち | 主 / 副 | 地の有無。主は本文紙の板 (1 画面に 1 つ)、副は罫だけの板 | `Button` の `variant` |
| 新規 | まだ開いていない | 小さな点 (滞留)。開くと消える | `Tabs` / `CluesPanel` の `.fresh` |
| 読ませる / 拾わせる | 本文 / HUD | 明朝 (`--font-read`) / ゴシック (`--font-hud`)。数字は `--font-figure` | |
| 重なり | 段 | `--z-*` (数値を直書きしない) | |

- 役ごとの色は作らない。誰かは顔と名前で分かる

## 常設の HUD

全フェーズで同じ座標に置く。左上に章の札と残り時間 (時間を持つフェーズだけ)、右上に手帳の入口と卓の 3 人 (発話中は輪が脈打ち、ミュートはマイク斜線の札、通信不安定は ! の札、通話にいない人は顔ごと沈む)。投票で切れたマイクが戻っていなければ、章の札の横に知らせを出す。
