# 台本 0: 導入（任意・初心者向け）

本編前にプレイヤーへ伝えるマダミスの基本説明。全員が経験者なら 0-2 は省略してよい。

## 0-1. はじめに

#### ◉対面で遊ぶ場合

　オンラインではなく対面で遊ぶ場合は、全員マイクをミュートにし、BGMは代表者の端末からのみ流れるようにするとよいでしょう。  

---

#### ◉マダミスとは？

　マダミスとは登場人物になりきって**物語を体験するゲーム**です。元はミステリーを題材としたものから始まりましたが、人が死なない事件を扱っているもの、そもそも事件が起きないものも存在します。  
　プレイヤー（ゲームに参加する皆さん）が演じるキャラクターにはそれぞれ**固有の物語・秘密・目的**などがあります。プレイヤーはキャラクター固有の物語を読み、秘密を守りながら、目的に向かって行動・選択していきます。  
　秘密を守るため、目的を達成するために必要であれば、**嘘をついてもかまいません**。ただし、世界観に合わない、キャラクターが考えそうにない嘘をつくのは控えましょう。  
　また、キャラクターはそれぞれ**異なる情報**を持っています。それらの情報をもとに、時には協力し、時には疑い合いながら話し合いを進めていきましょう。  

#### ◉キャラクターになりきる

　無理に声色を変えたり、役者のように演じたりしなくてもかまいません。  
　誰の発言か判別しやすいように**一人称**をキャラクターに合わせる、個別テキストに書いてあることをそのまま読み上げるのではなく**キャラクターとしての言葉に置き換えて話す**、キャラクターの**気持ちに沿って考える**などが、キャラクターになりきる際のポイントです。  

#### ◉楽しくプレイするために

<u>**時間を守る**</u>  
　多くのマダミスではタイマーが設定されている議論フェーズがあります。不用意に時間を短縮すると推理をする側が不利になり、延長すると犯人側が不利になります。特別な指示のある時以外は、基本的に**議論時間を守る**、**議論フェーズ以外のところで話し合わない**よう意識しましょう。  
　ただし、文章を読む速さは人によって違うため、キャラクターテキストや追加情報を読み込む時間は適宜延長してもかまいません。  

<u>**最後まで参加する**</u>  
　マダミスは途中で誰かが欠けてしまうとプレイが続行できなくなるゲームです。**最初から最後までプレイできるよう周囲の環境を整えて参加**しましょう。  

<u>**コミュニケーションゲームであると意識する**</u>  
　それぞれキャラクターとしての目的に向かって行動する中で利害が対立することがあるかもしれませんが、**演技を超えた強い言葉を使う、特定の人を無視するといった誰かが不快になる行為はしない**よう意識しましょう。  

## 0-2. マダミスの流れ・ルール（読み合わせ）

台詞は各キャラの担当者が、地の文とスタッフの台詞は指定の人が読む。

**春見**：基本的な構造のマダミスは「オープニング」→「キャラクターテキスト読み込み」→「議論」→「投票」→「エンディング」と進みます。  

**夏野**：**オープニング**では事件が起こるまでの出来事が描写されます。だいたい読み合わせ（今のこの画面のように順番にセリフが出てくる形式）になっています。  

地の文（このように吹き出しになっていない文章）は指定された人が読み上げ、  

**秋永**：吹き出しになっているセリフは、そのキャラクターを担当している人が読み上げます。  

**スタッフ**：それぞれが演じるキャラクター以外のNPCのセリフがある場合は、地の文と同じように、指定された人が読み上げます。  

**夏野**：**キャラクターテキスト読み込み**では、自分が演じるキャラクターの背景・事件当日の行動・秘密などを確認します。  
そのような個別のテキストはそのキャラクターの担当者だけが見られるものなので、誰かに聞こえるように文章を読み上げたり、他の人の画面を覗いたりしてはいけません。  

**秋永**：**議論**では、キャラクターテキスト、共通情報、調査で分かったことなどを元に、事件について話し合います。  
全員で話す「全体議論」と、何人かずつに分かれて話す「密談」があります。  
※このシナリオでは「全体議論」のみです。  

**春見**：キャラクターテキストの内容を話に出すときは「～と書いてある」と言ったり、そのまま読み上げたりしないよう注意しましょう。  
本当の情報を話すときにそのような話し方をしていると、嘘の情報を話したときにバレやすくなりますし、キャラクターらしさもなくなってしまうからです。  

**夏野**：「私は10時に書斎で仕事をしていたよ」のように、一人称を合わせ、キャラクターの言葉として話すと自然です。  

**秋永**：犯人を探し出そうと、つい真剣になってしまうこともあるかもしれませんが、相手が嫌な気持ちになるような強い言葉はできるだけ控えましょう。  
演技で敢えてそうした場合は、ゲームが終わってから一言伝えるとよいでしょう。  

**春見**：議論中は、それぞれの目標に従って行動することが大事です。例えば「犯人だとバレない」が目標の人物が「この事件の犯人は自分だ！」と言ってしまうと、議論の意味がなくなってしまいますし、秘密のある人物が「私の秘密は～」とすぐ話してしまうのもよくないでしょう。  

**夏野**：**投票**では、基本的に自分が思う事件の犯人に投票します。自分が犯人だと分かっている犯人役は、自分が最多票を獲得しないよう、疑われていそうな他の人に投票することが多いです。  

**秋永**：投票の際は相談ができないのが一般的なので、ミュートにして、これまでの議論を振り返りながら投票先を選びます。  

**春見**：**エンディング**は、投票の結果によって描写やセリフが変わります。オープニングと同じように、みんなで地の文やセリフの読み上げをします。
