# 台本 1: オープニング（全員で読み合わせ）

**読み上げ担当**: 地の文=春見、スタッフ（NPC）=秋永、各キャラの台詞=そのキャラの担当者

---

　注目されることを嫌っており、メディアへの露出は一切しないが、類まれなる推理力でその名を轟かせた“伝説の探偵”――斜六(しゃろく)。  
　2年前に引退した彼が、ある未解決事件への考察を元にして書き上げた探偵小説を公開するという。  
　一線を退(しりぞ)いた斜六が筆を執(と)った理由は何なのか、いったいどの事件が扱われているのかと様々な憶測が飛び交う中、お披露目会の当日がやってきた。  

　現在時刻は12:00、お披露目会が始まる２時間前。そして、会場3階に悲鳴が響き渡った直後である。  

**スタッフ**：準備についてお伝えしようと控室に伺ったら、斜六さんが血まみれで……。  

**スタッフ**：今朝ご案内したときは初対面の私にも優しく話しかけてくださって、あんなに元気でいらしたのに……。  

　第一発見者であるスタッフ数名がひどく動揺した様子で口々に状況を説明する。  

**夏野**：なるほど。皆さんが控室を訪れたときには既に亡くなっている状態だったと。  
警察は呼びましたか？  

**春見**：呼んだみたいだが、このお披露目会のせいで会場周辺は大渋滞。到着まで１時間弱かかるらしい。  
そもそもこれは事件なのか？  

**秋永**：胸から血を流しているのに凶器となりそうなものが彼の控室内に何もない。つまり自殺や事故ではなく、確実に他殺。  
そう思いませんか？  

**夏野**：そうですね。  
それから、この１時間くらいの間、エレベーターが故障しており、階段も清掃で封鎖していたようですので、犯人はここ3階にいることになります。  

**春見**：もっと言うなら、俺たち３人の中に、だ。  
スタッフは全員、複数人で行動してたみたいだからな。  

**秋永**：警察が来るまでの間、ずっとこの疑いの視線を浴び続けるのも嫌ですから、僕たちの中で誰が一番怪しいのか、話し合って決めてしまいませんか？  
そのために、まずはそれぞれこの１時間の行動を思い出しましょう。
