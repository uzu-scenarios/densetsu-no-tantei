# 再実装・移植の要件

媒体（オンラインのセッションツール、自作アプリ、対面・紙）は問わない。以下を満たせば作品として成立する。

## 必要な仕組み

| 仕組み | 用途 |
|---|---|
| 本人にだけ情報を渡す | 個別情報の配布 |
| 全員に同じ情報を見せる | あらすじ・登場人物・オープニング・共通情報・見取り図・エンディング |
| 時間を計る | 個別情報の読み込み 5 分・議論 22 分 |
| 同時公開の投票 | 犯人投票（3 人）・秘密の自己申告（夏野・秋永） |
| 投票結果による分岐 | エンディング 5 種の選択（[判定表](05_votes-scoring-endings.md#エンディング分岐)） |
| 得点計算 | ミッション 9 個（[得点表](05_votes-scoring-endings.md#得点表ミッション)） |
| BGM の再生（任意） | 段階ごとの切り替え（[BGM](01_game-flow.md#bgm)） |

証拠カード・調査・密談・キャラごとの分岐テキストはこの作品では使わない。

## 守るべきこと

- **情報の公開タイミングを守る。** 個別情報は読み込み開始時、共通情報は議論開始時、エンディングと真相は投票後（[公開タイミング](01_game-flow.md#情報の公開タイミング)）。早く出すと推理や駆け引きが崩れる
- **個別情報を他人に見せない。** 仕組みで隠せない環境では、覗かないことを事前に全員へ周知する
- **議論は 1 回だけ。** 議論後の投票と自己申告は相談なしで行う
- **エンディングは投票結果の 1 本だけを流す。** 他の 4 本は感想戦で公開する
- **秘密の自己申告は夏野・秋永だけ。** 春見は申告しない（春見の得点は 2 人の申告で決まる）
