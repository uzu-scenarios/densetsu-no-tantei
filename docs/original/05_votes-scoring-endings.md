# 投票・得点・エンディング分岐・真相

## 投票

### 投票1「殺害事件の犯人は？」

- 投票者: 春見・夏野・秋永の 3 人全員。1 人 1 票、相談不可
- 選択肢: 春見／夏野／秋永（自分自身も選べる）
- 集計: 「単独最多」= 他のどの選択肢より票が多いこと。3 人なので結果は「2 票以上の 1 人」か「1-1-1 の同票」のどちらか

### 投票2「あなたの秘密について議論中に指摘されましたか？」

- 投票者: 夏野・秋永のみ（春見は待機）。自己申告
- 選択肢: はい／いいえ
- 判断基準: 各自の個別情報の目標 3 つ目（夏野=本物の斜六であること、秋永=小説を盗み出したこと）が議論中に指摘されたか
- 用途: 得点判定（春見のミッション 2・3、夏野・秋永のミッション 3）と、エンディング 1/2 の分岐

### 推理の筋道（真相解説の要約）

1. 被害者の最終目撃は一見「11:40〜11:50 トイレでの斜六の電話の声」（秋永）に見え、そうすると 11:50〜12:00 が犯行時刻になるが、その時間は全員にアリバイがある。
2. 秋永が聞いたのは「昔聞いた斜六の声」であって白髪の男性の声ではない。白髪の男性が偽物で本物の斜六が別にいる（＝夏野）と気付けば、被害者の最終目撃は 11:10〜11:20 に繰り上がる。
3. 11:30〜11:40 は控室に出入りがないので、犯行は 11:20〜11:30 か 11:40〜11:50。11:40〜11:50 は春見（喫煙室、スタッフ証言）・秋永（トイレで電話を聞く）・夏野（電話の主）で全員埋まる。11:20〜11:30 は秋永がトイレ（スタッフ証言）、夏野が喫煙室（清掃後に現れた盗聴器を 11:40 に春見が見ている）。**空白が残るのは春見だけ**。
4. 凶器の遺棄時間（11:30〜11:40 のトイレ）も春見にだけ確保されている。

### 隠された設定

- 白髪の男性は、作家として鳴かず飛ばずの自分に嫌気がさし、姿が知られておらず引退済みの斜六の名を騙って自作の探偵小説を売り出そうとした。
- 夏野は春見・秋永の前で声色を変えていたため、斜六の声を知る秋永も気付けなかった。
- 秋永は 2 年前の未解決「2億円強奪事件」（四季銀行の現金輸送車襲撃）の犯人。斜六への挑戦状のつもりだったが、斜六は解かずに引退した。
- 春見の妹は斜六のボディーガードで、2 年前に斜六を庇って死亡。斜六（夏野）の引退のきっかけでもある。
